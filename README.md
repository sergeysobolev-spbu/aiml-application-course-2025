Запрос № 5
как в makefile убрать пусть из имени файла

```gpt
# Пример файла
SRC = /path/to/your/file.txt

# Убираем путь
FILE_NAME = $(notdir $(SRC))

all:
 @echo "Полное имя файла: $(SRC)"
 @echo "Имя файла без пути: $(FILE_NAME)"

```

как заменить имя папки в списке файлов в makefile

``` gpt 
# Исходные файлы с полными путями
SRC_FILES = src/file1.c src/file2.c src/file3.c

# Новая папка, в которую мы хотим переместить файлы
NEW_DIR = new_folder

# Заменяем "src/" на "new_folder/" в каждом файле
NEW_FILES = $(patsubst src/%,$(NEW_DIR)/%,$(SRC_FILES))

all:
 @echo "Исходные файлы: $(SRC_FILES)"
 @echo "Новые файлы: $(NEW_FILES)"
```
