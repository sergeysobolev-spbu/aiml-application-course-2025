# Учебные примеры для курса "Применение методов искусственного интеллекта и облачных технологий", весенний семестр 2025

Задача: Реализовать на языке С программу. Программа должна просчитывать оптимальный маршрут используя метод оптимизации "Муравьиный алгоритм". Начальные переменные стартовая и конечная точка, промежуточные точки и точки границ препятствий. 

Для генерации кода использовалась нейросеть Deepseek

Запросы для Deepseek

Напиши на языке C код для построения оптимального маршрута из точки A в точку B, заданных координатами на плоскости, в обход замкнутых 
запрещённых зон, вершины которых заданы географическими координатами.

Упрости этот код, не меняя название переменных и данные переменных

Добавь в эту версию кода алгоритм поиска обходного пути

Добавь в код поддержку пути с заданным количеством промежуточных точек

Добавь вывод графики, маршрута передвижения, точек и препятствий в виде поля с клетками

Добавь отображение всего пути. Путь должен отображаться символом @

Отобрази весь пройденный путь на сетке символами @ от точки к точке

Добавь в результат последовательность пройденных точек и их координат

Сам код программы не меняй. Добавь поиск и расчет оптимального маршрута с использованием муравьиного алгоритма. Выведи полный код программы, переда выводом проведи тесты на работоспособность.

Исправь ошибку в find_path_with_aco. Остальной код не менять. Проверь работоспособность программы.

Доработай код. С помощью муравьиного алгоритма должен быть построен кратчайший маршрут и начальной точки в конечную с учетом обхода препятствий. Путь обязательно должен проходить через промежуточные точки.

Запросы для проведения тестов

напиши для этого кода unit тесты на языке C, 
используй рекомендации MISRA C, 
принцип KISS, 
всё документируй следуя doxygen нотации, 
используй пакет CUnit
